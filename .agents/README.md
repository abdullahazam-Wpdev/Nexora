# NEXORA project skills

Each `skills/nexora-*/SKILL.md` has a separate trigger and provider-specific boundary. Load the matching skill for the task; do not blindly include all skills in a small model's prompt. These guide a coding agent working on the project. The tiny Core checkpoint does not learn capabilities by reading these files.

The current product executes explicit workspace commands and serves bounded model replies. Reliable natural-language planning, tool selection and autonomous agent generation have not been demonstrated. Add agent automation only with reviewed tools, interruption recovery and measured evaluations.
