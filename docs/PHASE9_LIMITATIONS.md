# Unmet Phase 9 targets and practical limits

- No professional assistant capability is demonstrated. Qwen beats the exposed
  three-task arithmetic regression but is weak on the expanded suite and exceeds
  the normal 900 MiB service cap under longer workloads. It is disabled by default;
  stable SmolLM2 remains weak. Hosted inference is not configured or presumed free.
- The owner-approved temporary 1,152 MiB study is complete; normal service cap is
  restored. No sustainable larger inference profile is silently enabled.
- The mixed suite was reused during protocol debugging and lost untouched final-holdout status. No new pristine expanded final score was produced.
- Corrected expanded mixed-language result is 2/17 in that study; three additional
  runtimes blocked. Several protocol reruns mean this is regression evidence,
  not an untouched generalization score. No prompts receive held-out test code.
- Node/TS unit and HTML/CSS static profiles work; real PHP/WordPress and FastAPI
  test runtimes, full Next builds and broad framework deployment are unsupported.
- Core's old tool target declined 6/16→5/16. New strict argument accuracy is 1/11
  and instruction accuracy 0/8. No Core 2.0 checkpoint is promoted.
- Retrieval 20/20 means deterministic literal field evidence, not semantic QA,
  source authenticity, independent fact-checking or verified publication dates.
- Streaming/cancellation are bounded/cooperative. Localhost endpoints trust one
  owner and are not a hardened public multi-user platform. Browser DNS guard and
  OS resource-limit limitations from Phase 8 remain documented.
- Cgroup MemoryPeak includes cache. Host process RSS was unavailable inside
  Flatpak; recorded zero samples must not be read as real zero memory.
- No training on private chats, extra major dataset/model download, system-wide
  package installation, GPU provisioning, purchase or paid fallback occurred.

Phase 10 should resolve the assistant's sustainable compute budget or configure
an explicitly authorized stronger hosted backend, then freeze a fresh task-family
holdout before model/prompt selection. Improve diverse licensed instruction data
and argument-level evaluations before considering larger independent Core runs.
