# OpenAI models offered through NVIDIA

Reviewed 2026-10-18 from [NVIDIA's publisher page](https://build.nvidia.com/openai). Its two listed models are distinct:

- [GPT-OSS-20B](https://build.nvidia.com/openai/gpt-oss-20b): text reasoning/chat. The existing NVIDIA client uses `openai/gpt-oss-20b` at `https://integrate.api.nvidia.com/v1/chat/completions`. The chat selector now includes this model. It requires `NVIDIA_NIM_API_KEY` and explicit hosted-inference consent. Only final answer content is displayed; private reasoning fields are not exposed. Current generation is **not live-verified** because no key is configured. No API charge was incurred. The [official OpenAI model documentation](https://developers.openai.com/api/docs/models/gpt-oss-20b) describes the released model; external capabilities are not Core achievements.
- [Whisper Large V3](https://build.nvidia.com/openai/whisper-large-v3): speech recognition, not a chat model. The UI's Whisper speech view accepts a mono WAV only when a separate speech service is configured. `POST /api/speech/transcribe` validates WAV size/duration and forwards to the documented [Speech NIM REST transcription API](https://docs.nvidia.com/nim/speech/26.05.0/reference/api-references/asr/http-asr.html) on explicitly configured `http://127.0.0.1:9000`. `NEXORA_WHISPER_BASE` must equal that URL. Maximum 2 MB / 30 seconds. Current service is **not installed/configured**, so the UI disables transcription and API returns a clear 503. No false speech-to-chat routing or invented transcript.

`GET /api/nvidia/openai-models` records capabilities/configuration and distinguishes these modalities. NVIDIA's public LLM `/v1/models` list returned GPT-OSS-20B; Whisper uses the separate speech stack and is not expected in that chat list. Hosted account quotas, entitlements and pricing must be checked before calls; a “Free Endpoint” label does not guarantee unlimited access or local weights.

Neither large model was downloaded or loaded on this 7.5 GiB Intel-only laptop. Manifest: `tooling/nvidia/nano4b-storage-manifest.json`; weights and license remain in ignored `artifacts/reference-models/nvidia/`.
