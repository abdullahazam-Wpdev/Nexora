# Delivery roadmap

- Phase 0: hardware inspection, isolated dependencies, Git, FastAPI, Next.js, SQLite migrations, local services and verification implemented. Optional Podman Compose supplied; containers not run because Podman is unavailable. PostgreSQL/Redis application adapters remain pending.
- Phase 1: tiny independent model, byte BPE, pipeline smoke experiment and checkpoint resume implemented. This is a numerical fixture, not a capable language model.
- Phase 2: inference, local artifact registry, experiment history and limited evaluation dashboard implemented. Standardized benchmarks, multiple named runs and robust registry promotion pending.
- Phase 3: project/memory/audit groundwork implemented. Authentication, role enforcement, durable queue and approvals pending.
- Phase 4: controlled coding/browser agents and evidence orchestration pending. Local browser QA is used to verify this application.
- Phase 5: business, creative and authorized defensive security modules pending.
- Phase 6: digital workforce and event-driven virtual office pending.
- Phase 7: multimodal research pending datasets, licensing and compute.
- Phase 8: GPU training pending future hardware and benchmarking.
- Phase 9: production auth, backups, monitoring and deployment hardening pending. Public hosting is disabled.
- Phase 10: original research pending reproducible baselines and evaluation.

Next milestone: durable multi-run experiment registry, real dataset selection for training, stronger data review, and role-based project permissions. Do not scale training before establishing memory budgets and dataset rights.
