# NEXORA AI OS

A working local research bootstrap: Next.js dashboard, FastAPI control plane and a tiny independently initialized PyTorch decoder. See [roadmap](docs/roadmap.md) for the actual delivered scope.

## Run

From this directory, after the initial build:

```sh
./scripts/start.sh
```

Dashboard: http://127.0.0.1:3000 · API docs: http://127.0.0.1:8000/docs

For development, run `.venv/bin/python -m uvicorn nexora.api:app --host 127.0.0.1 --port 8000` and, in another terminal, `PATH="$PWD/.tools/node/bin:$PATH" npm --prefix frontend run dev`.

## Reproduce setup

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --extra-index-url https://download.pytorch.org/whl/cpu -r requirements.lock
# Node 22+ required; this workspace includes a project-local Node installation.
export PATH="$PWD/.tools/node/bin:$PATH"
npm --prefix frontend ci
npm --prefix frontend run build
.venv/bin/python -m nexora.train --steps 160
.venv/bin/python -m nexora.train --resume --steps 10
./scripts/test.sh
```

No pretrained weights, commercial model API, external training corpus or paid service is needed. The bundled training data is generated by deterministic arithmetic code, not copied AI text. The tokenizer and model start locally from scratch. Tiny arithmetic output is not conversational intelligence.

## Storage and migration

Artifacts default to `./artifacts` and are excluded from Git. Set `export NEXORA_STORAGE=/mounted/ssd/nexora` before running services or CLI. Stop all writers, copy the complete artifact directory (including SQLite, tokenizer, result, safetensors and resume files), transfer source and lockfiles, recreate dependencies on the destination, set the same storage variable and run tests. Linux/CPU is the verified target; other accelerators need validation. NAS needs reliable locking; object storage is not directly supported. Do not copy a live SQLite database without its backup API.

Optional containers: copy `.env.example` to `.env`, set a password and run `podman compose up -d` from a host shell where rootless Podman/Compose is installed. The application currently uses SQLite, not these optional services. Container configuration has not been runtime-tested in the Flatpak environment.
